# Ralph Breaks the Internet — Multiplayer Quiz

## Como executar
1. Instale o Node.js.
2. Abra o terminal nesta pasta.
3. Rode:
   npm install
   npm start
4. Abra no navegador:
   http://localhost:3000

## Para jogar em vários celulares
O jogo precisa estar hospedado em um servidor acessível pela Internet (ou todos os celulares precisam estar na mesma rede local e usar o IP do computador).
Depois de hospedar, o criador abre o endereço, cria a sala e compartilha o QR Code/código.

## Regras
- 15 perguntas.
- 15 segundos por pergunta.
- Fácil = 1 ponto, média = 2, difícil = 3.
- As perguntas são embaralhadas a cada sala.
- As alternativas aparecem na ordem definida; para embaralhar também as alternativas, o servidor pode ser expandido sem alterar o ranking.
- Ranking é sincronizado pelo servidor.
